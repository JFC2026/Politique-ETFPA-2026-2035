# Politique ETFPA 2026–2035 — Application de restitution

Application web/mobile de restitution de la **Politique de l'Enseignement Technique, de la Formation Professionnelle et de l'Apprentissage 2026–2035** (République de Côte d'Ivoire, METFPA).

Quatre entrées de navigation : Enseignement technique · Formation professionnelle · Apprentissage · Mesures transversales. Budgets officiels, graphiques et produits/actions-clés fidèles au document de politique (version finale, octobre 2025).
